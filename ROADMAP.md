# Roadmap

## Next

- **Quieter All Apps.** Research first. Directions to try:
  - A plain text list, like Home, with an A–Z index on the side.
  - Banner-free icon grid (Apple TV icon proportions, name shown only on focus).
  - Smaller tiles in a 6–7 column grid, dimmed until focused, no header hint text.
  - Search by typing with the on-screen keyboard.
  Prototype two of these against the reference look before choosing.
